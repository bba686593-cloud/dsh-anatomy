# Anatomy 0.11.0 更新说明

发布日期：2026-10-12。本次更新解决公式库覆盖原表达的问题，并让画板的全局撤销、重做更明确。

## 数学表达可追加，也可逐条编辑

一个部位可以同时描述多条数学关系。例如，已有「输出数量 ≤ 输入数量」时，再补充「处理耗时 ≤ 允许时限」，两条都会保留。

- 选中部位打开公式库，默认「追加数学表达」。已有公式保留，新表达在同一部位单独显示。
- 点击某条的「编辑这条表达」，或在公式库选择编辑及对应条目，只更新这一条。
- 选择「新建独立公式」，创建可单独移动、选择并关联实现的公式图元。
- 右侧「说明 · 数学」逐条提供编辑框、实时预览和删除按钮。
- 公式模板插入光标处，保留编辑框已有内容；确认前不改变画板。

画板、工程导读、连线标签和人读、机读摘要会包含全部表达。追加或编辑保留原部位的程序映射、源码关联、稳定标识与扩展字段；所有表达继续经过校验。

## 手写公式的写入位置明确

手写数学结果可以追加到选中部位、编辑明确选定的一条表达，或新建独立公式。识别结果仍需校对并确认，默认追加不覆盖其他公式。

每条数学表达的「继续手写」可以恢复它自己的笔迹。中文说明与数学表达分别保留笔迹，追加表达后仍可继续编辑原表达。未确认的面板内容留在浏览器草稿中；确认后的结果和笔迹进入画板，可以保存和撤销。

## 全局撤销与重做

顶部「撤销」返回画板上一步修改，「重做」恢复刚刚撤销的修改。图形、说明、数学表达、程序映射、工程导读和自动排布共用撤销记录。字段尚未失焦时也能用顶部按钮撤销；绘制中的修改可以安全返回上一步，切回自动布局也可一步恢复原状态。

- 画板快捷键：Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做；Mac 可使用对应的 Command 键。
- 文本框内快捷键由文本编辑器处理，要返回整个画板的上一步时点击顶部按钮。
- 当前会话保留最近 60 步；刷新后不保证保留撤销记录。
- 撤销后做新修改会清空重做分支。
- 撤销与工程保存历史独立，不会删除已保存版本。要让 AI 采用撤销后的结果，再点击「保存修改」并选定新版本。

## 升级与兼容

更新插件后重新生成画板，打开返回的本地服务地址。现有工程数据、保存历史和页面选定版本继续使用，无需迁移。

Codex 本地安装沿用原入口，将实际插件目录更新后安装：

```bash
codex plugin marketplace add /绝对路径/dsh-anatomy
codex plugin add anatomy@anatomy-local
```

重新加载插件或在新对话启用 Anatomy。完整安装、本地识别依赖和调用方式见 [README](../README.md)。

原有图元的 `math` 保留主表达；新增的 `mathExpressions` 数组保存附加表达，每项包含稳定 `id` 和数学内容 `value`，并保留该条笔迹及扩展字段。旧画板只含 `math` 时仍可正常读取。自动布局按全部公式估算与测量内容，保留自由布局选项。

项目保存仍直接写入工程专用目录，AI 读取页面选定的完整版本，并核对选择修订、工程基线与源码证据。保存或撤销设计都不代表业务代码已经实现。

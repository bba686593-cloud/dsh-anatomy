# Anatomy 0.14.0 更新说明

本版本的更新提交已通过 Git revert 撤回，未改写 Git 历史，也不回滚用户画板与保存历史。当前版本见 [0.15.0 更新说明](RELEASE-0.15.0.md)；以下保留原发布记录。

发布日期：2026-10-13。工程的人读说明、数学关系和图片在同一张大画板上阅读和修改，编辑保持内容的原位置。

## 原位置编辑

双击文字或公式，直接在原位置书写；连线名称、图片图注和导读中的部位说明使用同样的编辑方式，其他图元持续可见。形状与公式工具按表达需要辅助绘制，不要求固定结构；编辑人读内容不再进入独立纸页。

点击画板其他部位会自动校验整张画板与公式语法，通过后提交当前修改；✓／Ctrl+Enter 完成，×／Esc 取消。公式输入内 Enter／Esc 只收起输入，保留草稿；Alt+= 追加公式。无效内容、中文组合输入和未确认手写会保留并阻止切换。

顶部撤销、重做有正在编辑的输入时先处理本次输入步骤，完成后继续使用全画板历史。图片、图形、文字、公式与图注都可撤销；「保存修改」先完成有效编辑，再写入项目。

程序映射仍由用户明确打开独立机读窗口，程序表达和源码依据不进入人读画面。

原位编辑时打开手写识别，校对后的结果回到同一部位草稿，完成编辑才确认到画板。恢复保留原公式目标，未确认笔迹不因切换部位而清除。

## 本地嵌入图片

左侧「图片」选择 PNG、JPEG 或 WebP，也支持剪贴板粘贴和拖入。默认插入位置避让已有内容，拖入按落点放置；图片可移动、缩放和旋转。双击图注原位编辑自然语言说明，同一部位可关联程序映射与实际源码依据。

单图最多 6 MiB，整张画板图片累计最多 8 MiB。图片嵌入本地画板 JSON，和图注一起保存到工程专用目录，保留在历史版本与完整机读中；不需要另外上传图片或维护原文件位置。MCP 把选定版本图片作为标准图片内容交给 AI，同时提供尺寸、内容指纹与完整结构化数据供严格核对。

图片本身不证明设计正确或实现完成，关联与说明仍需复核。

## 保存与严格实现

项目保存只包含已经确认的画板意图，页面选定版本仍是 AI 应用的依据。选择修订、工程基线和源码哈希继续严格核对，拒绝陈旧选择与冲突覆盖；撤销不删除项目历史。

保存不代表业务代码已经实现。AI 必须读取选定完整版本，结合自然语言、数学与图片说明对照真实源码，实施改动并运行相关测试。

## 升级与验证

更新插件后重新生成画板，打开工具返回的本地服务地址。已有图元、公式、程序映射、保存历史与选定版本继续使用。安装和调用方式见 [README](../README.md)。

- `npm test`：覆盖原位编辑、自动提交、输入保护、图片往返保存与机读、全画板撤销与选定版本应用。
- `npm run test:ocr`：覆盖本地识别服务、项目版本接口与访问边界。

结构与源码证据继续执行严格检查；自然语言、数学和图片的完整含义仍需实际工程与测试核对。

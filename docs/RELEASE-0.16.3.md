# Anatomy 0.16.3 更新说明

发布日期：2026-10-13。本次修复点击左侧「识别」清空圈选的问题，并支持普通文字、排版公式与导入图片。

## 圈选与识别

完成套索圈选后，点击左侧「识别」始终打开「中文说明／数学公式」选择。原先只有自由笔迹或公式图形才能进入选择；圈到普通文字、排版公式、图片或空白时会重新进入套索，导致圈线消失。

选择类型后，页面准备圈内预览并自动识别。普通文字、排版公式、导入图片以及含这些内容的图形，都按原位置与旋转绘制，图像只保留圈内部分。没有可识别内容的区域显示明确提示，类型窗口和圈线保留，不发出空识别请求。

校对并确认后，普通文字、排版公式和导入图片保留原对象，在圈选位置新增结果；自由笔迹和公式图形沿用原有的圈内替换与圈外保留。混合来源的原稿与程序映射继续可追溯。取消不会修改工程，确认可撤销。

## 升级与验证

升级后重新生成画板并打开服务地址；旧 HTML 持有旧代码。已运行的 MCP 连接需重启才能使用更新后的工具代码。工程画板与历史继续兼容。

`npm test` 的 553 项 JavaScript 检查全部通过（129 项端到端、298 项 Node、126 项兼容渲染）；`npm run test:ocr` 的 9 项 Python 服务检查全部通过。新增 8 项交互回归覆盖普通文字、排版公式、导入图片、混合来源、空选区、取消、来源变化、确认与撤销、空心框内正文、移离线条的标签，以及真实圈内光栅化。

浏览器使用演示普通文字和排版公式的预设圈选，验证左侧按钮保留圈线并打开类型选择；真实 Canvas 预览保留圈内内容，两种模式均调用本机模型返回候选。验证后保留原稿，工程内容没有因识别预览而变化。

识别候选仍需校对；模型没有改动，复杂手写的准确率仍取决于本机识别模型和实际笔迹。

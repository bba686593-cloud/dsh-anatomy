# Anatomy 0.16.2 更新说明

发布日期：2026-10-13。本次修复圈选完成后左侧「识别」的入口：先选中文或公式，再自动识别。

## 操作步骤

1. 在画板上用「套索」或 Q 按住拖动，松手完成圈选。
2. 点击左侧「识别」，选择「中文说明」或「数学公式」。
3. 页面准备圈内预览后自动开始本机识别，无需再次点击「识别笔迹」。
4. 校对结果并确认，放回原圈选位置；圈外内容、原笔迹与来源映射保留。

尚未圈选时，左侧「识别」先进入套索，完成圈选后再次点击即可选择类型。取消类型选择保留当前圈线与画板内容，也不增加撤销记录。套索操作条原有两个识别预览入口继续可用。

只有圈内预览成功且原稿与选定版本仍一致时才提交请求。重复点击选择、关闭预览、捕获失败或来源变化会停止自动识别；识别失败时保留原稿与实际服务反馈，可重新连接或重试。候选结果仍需人工校对和确认。

## 升级与验证

升级插件后重新开启会话或重启 Anatomy MCP 连接，再调用 `anatomy_render` 重新生成画板，打开返回的服务地址。旧 HTML 内嵌旧入口代码，仅刷新旧文件不会应用修复；工程数据和已保存历史继续保留。

`npm test` 的 545 项 JavaScript 检查全部通过（129 项端到端、290 项 Node、126 项兼容渲染）；`npm run test:ocr` 的 9 项 Python 服务检查全部通过。新增 6 组交互回归覆盖中文／公式分流、自动提交、保留圈外内容与撤销、取消及重复点击、异步预览失败与取消、圈选来源和选定版本变化。

浏览器使用演示原笔迹的预设圈选检查左侧入口，确认类型选择窗口正常显示，两种选项都自动调用本机模型并返回可校对候选，保留原稿不会修改工程。

识别后端与模型没有改动。服务需要现有的本机 Python 识别依赖；回归检查请求流程和内容保留，不代表复杂手写的识别准确率。

# Anatomy 0.15.0 更新说明

发布日期：2026-10-13。画板以自由绘图为主要操作，左侧快捷栏只帮助插入内容，图形、笔迹、文字和公式可独立处理。

## 自由编辑图形

- 「画笔」或 P 直接保留笔迹，进入画板与项目保存，不要求先识别。
- 「橡皮」或 E 为图元橡皮，大小 6–100 px。「擦笔迹和内容」局部擦笔迹和框线，文字、公式按整段处理；「擦整个图元」删除整个对象。不提供图片像素或字符内部擦除。
- 选中对象有八个缩放手柄和上方旋转手柄，多边形橙色顶点与连线起终点可拖动。
- 选择栏可改形、直接删除；「拆开框与内容」生成独立文字和公式。拆分对象与擦除片段保留映射、源码锚点和扩展字段，记录原对象来源。
- 绘图、擦除、改形和拆分继续进入全画板撤销、重做。

绘图、变形、插入与手写确认采用自由布局，不自动重新排布；要整理画面时明确使用「自动排布」。人读文字与数学仍可原位编辑，程序映射按需独立打开，没有独立人读纸页。

## 原笔迹与打印公式

选中笔迹点击「识别为公式」，识别、校对并确认后在原位置排版；「原笔迹／排版公式」切换显示，完整原稿与源码映射保留。面板内「保留笔迹，不识别」不需要识别结果，直接保留所画内容。

擦改笔迹或修改公式后，旧识别结果不再代表当前表达，需重新核对。未识别笔迹只保存真实几何与已有说明，不声称 AI 已理解其数学内容，也不补造公式。程序映射连接人的表达和真实实现，上层语义仍须作者与 AI 结合工程复核。

## 撤回与兼容

v0.14.0 的更新提交已通过 Git revert 撤回，Git 历史保留。新版继续读取已有图片和保存版本，不回滚用户的画板数据或项目历史。

图片仍可本地嵌入、移动和缩放，程序映射按需独立打开。页面选定版本、选择修订、工程基线与源码哈希继续严格核对；保存设计不代表业务代码已经实现。

## 升级与验证

更新插件后重新生成画板，打开工具返回的本地服务地址。安装、图片数据与项目保存方式见 [README](../README.md)。

- `npm test`：465 项 JavaScript 检查通过，其中 129 项端到端、210 项 Node 和 126 项兼容渲染检查；包含绘图数据与交互回归，覆盖局部擦除、几何编辑、形状转换、映射与扩展字段保留、原笔迹恢复及项目兼容。
- `npm run test:ocr`：9 项 Python 服务检查通过，覆盖本地识别服务、项目版本接口与访问边界。

自然语言、图形、笔迹和数学关系的完整语义仍需真实实现与测试核对。

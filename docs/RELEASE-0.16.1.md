# Anatomy 0.16.1 更新说明

发布日期：2026-10-13。本次修复套索操作：按住拖动、松手闭合，圈选期间专注绘制边界，完成后可以立即再圈。

## 连续圈选

选择左侧「套索」或按 Q，像使用画笔一样按住鼠标、触控笔或手指拖动，松手自动闭合。取消逐点点击与回车拼圈；一次完整拖动形成一个选区。

进入套索会隐藏旧选择与控制手柄，鼠标经过、单击和双击图元不会打开组件编辑。松手后仍保持套索模式，操作条仅提供圈内「识别中文」与「识别公式」。可以直接再圈一块区域；需要移动、缩放、旋转或编辑组件时，按 V 或点击「选择」。

正在拖圈时，滚轮和除 Esc 外的键盘动作暂停，避免缩放、删除或编辑中断边界绘制。Esc、拖动取消或浏览器失去指针捕获会取消当前圈，同时保留套索模式。圈线随输入更新自身，不重排工程中的文字、公式和其他图元。

## 内容、历史与严格核对

圈选或取消只改变当前选区，不修改工程内容，也不增加撤销记录。识别确认后才在圈选位置应用结果，保留圈外笔迹与图形像素、原稿和各来源的程序映射；中文与公式候选仍需校对。

现有画板、公式图形、原笔迹、图片与工程保存历史继续兼容，无需迁移或删除旧版本。AI 仍读取页面选定版本，核对选择修订、当前图片指纹、工程基线与源码证据；保存意图和图形校对不证明业务源码已经实现。

## 升级与验证

升级插件后重新开启会话或重启 Anatomy MCP 连接，再调用 `anatomy_render` 重新生成页面并打开返回的地址。已运行的 MCP 进程和旧 HTML 持有原代码，单独刷新旧文件不会切换到新的套索实现。工程数据与已保存历史保留。

- `npm test`：539 项 JavaScript 检查全部通过（129 项端到端、284 项 Node、126 项兼容渲染）；新增 8 项套索回归，覆盖连续拖圈、重复圈选、图元事件隔离、滚轮与键盘中断、Esc／拖动取消／指针捕获丢失，以及画板内容和撤销历史保留。
本次未改动识别后端。实际浏览器检查了组件命中与光标隔离、跨组件拖动、连续圈选事件，以及切回选择后的控件恢复。

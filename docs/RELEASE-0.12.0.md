# Anatomy 0.12.0 更新说明

发布日期：2026-10-12。画板现在从选中部位附近直接进入编辑，常驻右侧面板移除；程序映射和工程导读按需打开独立窗口。

## 在画板上编辑

- 选中部位显示附近操作栏，双击文字或公式进入编辑。
- 自然语言说明在原部位就地修改，确认后生效，取消保留原内容。
- 数学表达保留追加、编辑指定条目和新建独立公式；追加继续保留已有公式与源码映射。
- 明确点击「程序映射」才打开机读窗口，查看和编辑程序表达、实现说明与源码关联。人读画面只用自然语言和数学。

编辑确认前检查整张画板，通过后整次变更进入一个撤销步骤。编辑中的草稿先确认或取消，再撤销画板；项目保存只包含已经确认的意图。

## 工程导读独立阅读

点击「工程导读」打开窗口，阅读工程目的并选择路线；开始阅读后，小阅读卡片提供上一步和下一步，逐步定位具体部位。画板显示自然语言、数学关系和命名连线，程序依据通过同一部位的映射窗口查看。阅读路线用于讲解，不代表运行顺序。

编辑导读可以修改说明、增删或调整步骤。确认前校验整张画板，确认后作为一次修改保存；取消保留原导读。关闭窗口会暂存未确认草稿，再次打开可以继续修改。

## 保存和严格对照

「保存修改」继续直接写入工程专用目录，每次产生不可变的完整版本。页面可选择历史版本供 AI 读取；选定版本、选择修订、工程基线与源码哈希的严格核对保持不变，拒绝陈旧选择与冲突覆盖。

保存确认的设计意图不证明业务源码已经实现。AI 仍须读取页面选定版本，对照真实源码落实自然语言与数学约束，并运行相关测试、复核实现映射。

## 升级与验证

更新插件后重新生成画板，打开工具返回的本地服务地址。原有图元、数学表达、程序映射、项目历史与选定版本继续使用，无需迁移。完整安装与调用方式见 [README](../README.md)。

- `npm test`：覆盖画板编辑、确认和取消、导读草稿、全局撤销、数学表达与项目版本应用。
- `npm run test:ocr`：覆盖本地识别服务、项目版本接口与访问边界。

发布验证通过 376 项 JavaScript 检查和 7 项 Python 检查。实际浏览器验证覆盖双击文字与指定公式、独立导读、程序映射、撤销重做，以及窄窗口下的定位和滚动；历史切换等待期间的新编辑经过竞态回归确认会保留。

结构与源码证据继续执行严格检查；自然语言和公式的完整语义仍需真实实现与测试核对。

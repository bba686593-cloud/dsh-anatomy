# Anatomy 0.13.0 更新说明

发布日期：2026-10-13。双击部位即可打开一张纸页式文稿，在同一页阅读和修改自然语言与数学关系。

## 统一文稿编辑

- 文字、图形、公式和连线都使用「工程文稿」，自然语言直接点击书写。新建文字、公式与导读中的部位说明也使用这一页。
- 全部数学表达排版在同一页，点击公式展开数学记法输入和预览；Enter 继续写说明，Esc 收起输入。
- 「Σ 插入公式」或 Alt+= 直接新增数学表达，保留原公式。左侧公式库继续提供模板、符号和独立公式操作。
- 文稿内「↶／↷」和 Ctrl+Z／Ctrl+Shift+Z 跨文字、公式撤销与重做。
- 「完成编辑」通过全板与公式语法校验后，把整页修改作为一个画板撤销步骤；「关闭」暂存可恢复草稿，「放弃本次修改」保留原内容。
- 程序映射由用户明确打开独立窗口，代码与源码关联不进入人读文稿。

选中部位只有编辑文稿、程序映射与「⋯」三个入口；图形外观、复制、层级和删除位于更多操作中。原部位的笔迹、程序映射、源码关联与稳定标识继续保留。

## 手写先放入文稿

文稿内「手写输入」的识别结果经校对后放回当前草稿。中文追加说明；数学编辑当前公式，没有活跃公式时追加一条。无需额外选择放置位置，点击「完成编辑」才确认到画板。恢复笔迹保持原公式目标，原有公式和映射保留。

## 保存与严格实现

工程导读继续使用独立窗口和小阅读卡片。顶部撤销、重做作用于已经确认的画板修改；文稿先完成或放弃编辑，再操作画板撤销。

「保存修改」继续直接写入工程专用目录，页面可以选择历史版本供 AI 读取。选定版本、选择修订、工程基线与源码哈希的严格核对保持不变，拒绝陈旧选择与冲突覆盖。

保存确认的意图不证明业务代码已经实现。AI 仍须读取页面选定版本，对照真实源码落实自然语言与数学约束，运行相关测试并复核映射。

## 升级与验证

更新插件后重新生成画板，打开工具返回的本地服务地址。已有画板、数学表达、程序映射、保存历史与选定版本继续使用，无需迁移。安装和调用方式见 [README](../README.md)。

- `npm test`：覆盖文稿编辑、完成和放弃、草稿恢复、文字与公式共同撤销、手写返回草稿、数学追加、项目版本应用与旧格式兼容。
- `npm run test:ocr`：覆盖本地识别服务、项目版本接口与访问边界。

结构与源码证据继续执行严格检查；自然语言和数学的完整语义仍需结合真实实现与测试核对。
